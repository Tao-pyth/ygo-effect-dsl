# Redacted local diagnostic bundle

Status: v1.0.0 support contract.

The local diagnostic bundle is generated by:

```powershell
python -m ygo_effect_dsl support-bundle --out support-bundle
```

The bundle is local-only and contains a `manifest`, diagnostics, a `redaction report`, schema version fields, size limits, retention policy, and canary tests. Do not automatically upload this bundle. Users and maintainers must review it before sharing.

The bundle may include package version, Python/runtime version, support matrix-relevant bridge versions, external asset readiness, job status summaries, recent safe error categories, artifact digests, and redaction audit results.

The bundle must not include full deck lists, private hands, raw payloads, tokens, absolute personal paths, crash dumps, worker stdout/stderr text, raw Bridge frames, private card identity, seeds, request signatures, complete state hashes, source Route IDs, or source Replay digests.

Retention policy: keep local bundles only for the active support request. Delete local copies after support closure unless an incident extension is explicitly documented. CI and committed release evidence store only sanitized evidence; private diagnostic bundles are never committed or bundled into release artifacts.
